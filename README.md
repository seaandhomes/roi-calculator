# Kalkulator ROI nieruchomości za granicą

Prosty, statyczny kalkulator (HTML + JS, bez zależności) do szacowania rocznego zwrotu z inwestycji (ROI) oraz okresu zwrotu dla zakupu nieruchomości pod wynajem za granicą.

## Jak to działa

Kalkulator liczy:
- roczny przychód brutto z najmu,
- roczny przychód po uwzględnieniu pustostanu,
- roczny zysk netto po odjęciu kosztów utrzymania,
- ROI (zwrot z inwestycji) w %,
- szacowany okres zwrotu inwestycji w latach.

## Jak uruchomić

Wystarczy otworzyć `index.html` w przeglądarce — nie wymaga serwera ani instalacji żadnych zależności. Można go też hostować za darmo przez GitHub Pages (Settings → Pages → branch `main` → folder `/`).
